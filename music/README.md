# music

把你们的音乐放在这个文件夹。

两个人都在线的时候，网页会从这里随机挑一首放，一首完了接下一首，
人一走就慢慢淡掉。两个人听到的是同一首、同一处。

顶栏的「选歌」会列出这里的全部曲目，挑一首两边一起换。
右上角的 ♫ 只关自己这边的耳朵，TA 那边照放。

- 认得的格式：`.mp3` `.m4a` `.aac` `.ogg` `.oga` `.opus` `.wav` `.flac` `.webm`
  （最稳的是 mp3 和 m4a，什么浏览器都放得出来）
- 文件名就是曲名，顶栏和「选歌」清单里显示的都是去掉扩展名的那截
- 加歌不用重启服务器，每次要清单都是现读文件夹
- 以 `.` 开头的文件会被跳过

音频文件本身不进 git（见 `.gitignore`），只有这份说明进。
