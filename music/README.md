# music

音频文件存放在该目录下。

双方均在线时，页面从该目录中随机选择一首播放，一首结束后自动接续下一首，
一方离线后逐渐淡出。两端播放的是同一首、同一进度。

点击顶栏的「选歌」会列出该目录中的全部曲目，选定后两端同时切换。
右上角的 ♫ 仅控制本端的音频输出，对端不受影响。

- 支持的格式：`.mp3` `.m4a` `.aac` `.ogg` `.oga` `.opus` `.wav` `.flac` `.webm`
  （其中 mp3 与 m4a 兼容性最好，各浏览器均可播放）
- 文件名即为曲名，顶栏与「选歌」清单中显示的是去掉扩展名后的部分
- 新增曲目无需重启服务端，每次请求清单时都会重新读取目录
- 以 `.` 开头的文件会被跳过

音频文件本身不纳入版本库（见 `.gitignore`），仅本说明文件纳入。
